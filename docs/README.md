# Finance Tracker Docs

This directory holds project context for contributors and coding agents.

## Recommended Read Order

1. `../AGENTS.md`
2. `overview.md`
3. `architecture.md`
4. `domain.md`
5. `status.md`
6. `roadmap.md`

Read `working-style.md` for additional collaboration preferences that complement `AGENTS.md`.

## File Guide

- `overview.md`: product purpose, goals, stack, and current scope
- `../AGENTS.md`: repository-level agent instructions and working rules
- `working-style.md`: collaboration rules and response preferences
- `architecture.md`: layer responsibilities and dependency direction
- `domain.md`: aggregate model, business rules, and domain decisions
- `status.md`: implemented functionality, API surface, tests, and current gaps
- `roadmap.md`: next work, deferred work, and current constraints
